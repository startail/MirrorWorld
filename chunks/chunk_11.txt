A suggestion popped into my head while playing today - a movement tile, set like the Trap, with a "reload" similar to the Crossbow.

The tile first marks the spot you're on, and changes to a teleport (and on cooldown). Using the teleport tile will then swap you with anything that happens to have moved on that space, but would remove the marked spot.

Namewise, Warp would be the most succinct.

Example:

> Warp
> Base Cooldown - 5~6
> Mark the spot you are currently standing on. The tile will change to Return.
> 
> Return
> Base Cooldown - 5~6
> Return to and remove the spot you marked with Warp, swapping positions with a target if it's on the mark.

I'm not certain if it should be a "Free" tile or not by default, but given that it's *only* utility, it would keep it on par *with the rest of the non-damaging movement tiles.
